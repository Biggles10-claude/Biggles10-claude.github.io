Do

CHECK · 15 MINCheck any MCP server that fetches a URL for an SSRF guard. SSRF (server-side request forgery) means a tool fetches whatever address the agent passes it, including internal ones. One researcher got the same SSRF bug fixed in MCP servers from Google, JPMorgan, Weaviate, France's DINUM and Tangerang's government. Google's MCP Toolbox for Databases is CVE-2026-14540, rated 8.0, in versions 0.3.0 to 1.4.0. He runs 30+ MCP servers, including crawling ones. For any server he wrote that takes a URL, check that it resolves the hostname and blocks private and metadata IP ranges before fetching. Don't rely on just rejecting literal IPs, because that is the exact bug in the Tangerang server. The Next Web, 6 Oct

1 · NeuDecide (bucket 5 on-device + 7 audio)

Primary: README · Neuphonic blog (08/10/2026) · weights (HF, Apache-2.0) · demo Space · PyPI

What it is. It's a tiny “voice-action” model. You give it audio and a list of your app's actions, written as JSON schemas. It returns which action to run and with which arguments. It never writes out the words. Everyday comparison: a normal voice assistant is a stenographer who hands notes to a clerk. NeuDecide is one clerk who just listens and presses the right button.

“NeuDecide converts speech directly into function calls. It's 43 MB, can run on a single thread via ONNX Runtime, and needs no GPU or internet connection once downloaded.” (README)

Must-beat. For the job of voice commands inside the paid iOS and Android apps, he runs nothing on device today (the snapshot's known gap). The nearest shelf candidate is the Whistle → Needle cascade from the 5–7 Oct boards. NeuDecide beats that structurally: one model (three ONNX graphs, 55.5M parameters, 43 MB) replaces two models (176M parameters, 52 MB) and drops the transcript step. The accuracy gap is the vendor's claim, on SLURP spoken home-assistant commands with 10 tools. The comparison set is two Parakeet cascades, Whistle → Needle 3, and Voxtral Mini 3B:

README table: “SLURP | Exact match | 37.5% | 7.1% | 1.9% | 6.9%” (NeuDecide | Whistle → Needle 3 | Parakeet 660M → FunctionGemma | Voxtral Mini 3B)

Gate 1 · existence: PASS. I checked the snapshot. The factories have no on-device AI, which is a named known gap. The earlier picks on that shelf cover chat (Edge0), embeddings (EmbeddingGemma 2), a runtime (expo-local-llm) and speech-to-text (Whistle). None of them maps speech to an action in one model. I didn't compare it to Whisper on the Strix box, because that's a server job.

Gate 2 · fit: Windows desktop for the desk test, then a factory test phone. It runs on CPU only. Resident GPU memory: 0 GB / 24 GB = 0. System RAM: the vendor measured a peak of 146–174 MB. On the desktop that's 0.174 GB / 32 GB = 0.005. The vendor measured on a Samsung S24+ (82 ms to call, 267 ms to load), not on his phones. His test phones aren't in the snapshot.

Gate 3 · silicon. AMD, ROCm, Strix, Vulkan, unified memory, Linux, RTX 4090, RTX 2070 Super and RTX 5070 Ti are all ABSENT from the README. NVIDIA appears only as the credit for the speech encoder. iOS and Android are ABSENT as SDKs. The README lists only a Python package (Python 3.10–3.13). Measured on his gear: Not proven here.

Honest limit. There's no iOS or Android SDK. To use it in an app, the factory would have to run the three ONNX graphs, the tokenizer and the decode loop itself, and that isn't documented. It's English only, takes at most 30 s of audio, and works best with 10 tools or fewer. In the vendor's own test, it produced a set_timer call from 30 s of low-level noise. It has no confidence score, so it needs a voice-activity gate or a “no action” tool in front. On SNIPS, where arguments are free-form names, transcript cascades still fill arguments better. Every accuracy number is the vendor's.

Try this weekend (Windows desktop, browser only). First step, about 20 min: open the demo Space. I confirmed it returns HTTP 200 but didn't use it. Pick a device, then say 10 commands, including 3 with a TV or fan running. Done signal: at least 8 of 10 clean commands give the right action and the right argument. Stop rule: stop if it fires an action on background noise more than once, or if fewer than 7 of 10 are right. Then it stays shelved.
