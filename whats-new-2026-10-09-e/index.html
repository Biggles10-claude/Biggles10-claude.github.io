Closest near-miss: Qwen-Image-2.1-Turbo

Primary sources: HF model card · Qwen announcement (9:24pm AWST) · diffusers v0.41.0 notes · LICENSE

What it is. It's a sped-up checkpoint of Qwen-Image-2.1. It makes images from text, and it edits images from plain-English instructions, including from several reference pictures. Everyday comparison: same chef, same recipe book, but the dish is done in 8 stirs instead of 40.

“an accelerated checkpoint of Qwen-Image-2.1 for text-to-image generation and image editing with 8 denoising steps. It uses the same 7B visual generation architecture” (model card)

The base model's card uses num_inference_steps=40. Qwen gives no time or speed figure for Turbo, only the step count.

Must-beat (fails). For local image making and editing, he runs ComfyUI with Krea on the 4090. Turbo would add instruction edits, multi-reference composition and native transparent (RGBA) output, at 8 steps. But the licence says:

“FOR NON-COMMERCIAL PURPOSES ONLY” … “‘Non-Commercial’ shall mean for research or evaluation purposes only.” (Qwen Research License)

His image jobs feed paid apps, games, sprites and X content. So it can't take over the job it would need to beat.

Gate 1 · existence: the job is owned (ComfyUI with Krea). Qwen-Image 2.1 is already on the do-not-repeat list. Turbo counts as a new version, so I weighed it on its own.

Gate 2 · fit (4090 desktop). The full-precision (bf16) files are 14.23 GB for the transformer, 17.53 GB for the text encoder and 0.68 GB for the VAE. Loaded all at once, the weights alone are about 32.4 GB / 24 GB = 1.35, so they don't fit. With one component on the GPU at a time, the largest is 17.53 / 24 = 0.73 of GPU memory, and the rest waits in RAM (about 14.9 / 32 = 0.47). Neither figure includes working memory for 2K images. Neither is measured. The Strix Halo box could hold all of it (32.4 / 123 = 0.26), but see Gate 3.

Gate 3 · silicon. The card says “Install a CUDA-compatible PyTorch build”. AMD, ROCm, Strix, Vulkan and unified memory are ABSENT. So are RTX 4090, RTX 2070 Super and RTX 5070 Ti. On his gear it's Not proven here.

Honest limit. The card's install line is pip install git+https://github.com/huggingface/diffusers.git, which installs unreleased code and breaks the 7-day rule. The needed change (PR #14950) shipped in diffusers 0.41.0, uploaded 6 Oct, 2:24pm AWST. So the pinned line is pip install diffusers==0.41.0, and it works from Tue 13 Oct, 2:24pm AWST. Community GGUF and ComfyUI repacks appeared within hours. The ComfyUI one I opened has no model card, so I don't trust it yet.
